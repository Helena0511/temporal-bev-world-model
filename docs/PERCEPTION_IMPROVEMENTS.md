# 感知逐项改进实验

用户已授权依次实现、训练和测试各项建议。原融合/联合实验继续运行；本轮使用独立训练入口，
等待原流水线结束后，在同一张物理GPU 7上顺序执行，不同时启动第二张GPU训练。

主目录：`runs/city_phase1/perception_improvements_v1/`。
`plan.json`记录预先确定的数据、初始化、预算和晋级规则；`status.json`记录当前任务；
`comparison.json`、`comparison.csv`、`RESULTS.md`在每项完成后更新。

## 单项变体

| 名称 | 相对新baseline唯一改变的内容 |
| --- | --- |
| baseline | ResNet50/FPN、32通道、1层空间交叉注意力、256×448、CE/Dice |
| spatial3 | 空间交叉注意力1→3层 |
| resolution384 | 图像256×448→384×672 |
| focal_dice | CE替换为γ=2的focal CE，前景Dice保持不变 |
| channels64 | 特征通道32→64 |
| center_aux | 新增中心高斯热图与亚格偏移辅助头；原分割监督/指标保留 |

这些是各自对baseline的单因素对照，不是把所有改动叠在一起后猜测贡献。
中心辅助损失权重预先固定为0.1，不在官方验证上调参；它需要重新训练，不能直接用于旧checkpoint。
本轮未启动显式深度改造或0.5m全范围栅格实验。

## 固定条件

从原22,480条官方训练序列中按场景轮询选2,048条训练序列，覆盖667个场景；
另取32个互斥的官方训练场景作为开发集，共256条序列。
原4,819条官方验证序列不进入训练或开发集。
开发场景划分seed 20261015；模型seed 0；数据顺序使用独立生成器seed 12345，
因此增加网络层数消耗的随机数不会改变训练数据顺序。

各候选从同一个**未做感知训练**的ImageNet初始化control出发，所有名称/形状一致的权重逐项复制；
新增层或通道变化导致不能复制的张量会在manifest中完整记录。ResNet50 body始终全部严格匹配。
不把重新初始化后的大模型与额外续训的旧模型做不等预算对照。

筛选预算：4轮、微批次2、累积2次，有效batch 4，各2,048次优化器更新。
Dice按固定微批次计算，再按样本数平均梯度；所有候选计算方式一致。
该目标不等同于直接用batch 4计算一次全batch Dice，不宣称二者数值等价。
BN、stem和layer1沿用固定规则；主干学习率为其他参数的0.1。

## 执行顺序和判定

1. CPU验证初始化、梯度、目标几何、梯度累积及数据顺序恢复等契约。
2. 原联合训练退出后，冻结本轮Python源码及SHA256。
3. 每个候选依次用真实数据完成2次优化器更新及小样本验证，检查显存/非有限损失。
4. 顺序训练baseline及5个单项变体，每轮在固定开发集验证，按前景mIoU选best。
5. 在查看官方验证结果之前，按开发集固定规则锁定最多两个晋级候选。
6. 所有筛选best checkpoint均在4,819条官方验证上复核，明确标记为小数据训练结果。
7. 若存在晋级候选，从共同起点重新训练完整数据baseline和晋级候选：
   22,480训练/4,819验证，4轮、微批次2、累积4次、有效batch 8，各11,240次更新。

晋级需要开发集前景mIoU和human IoU均提高，vehicle IoU下降不超过1个百分点，
human精确率下降不超过2个百分点；按开发集前景mIoU排序选最多两个。
这是预先确定的筛选规则，不是已验证的质量门槛，也不表示未晋级方案在更大预算下一定无效。

除了全范围IoU、精确率和召回率，还记录0–20/20–40/≥40m分层、1m/2m GT格子覆盖，
以及20–40m可见度≥60%且有传感器点的对象中心2m覆盖。
对象覆盖不做一对一实例匹配，不是检测召回；必须结合格子精确率检查误报。
每阶段的比较都以同阶段新baseline为准，旧完整数据19.131%只作为历史背景。

## 可恢复性

每200次更新及每轮结束保存模型、优化器、轮内位置、最佳指标与RNG状态；
恢复时从同一确定性排列的正确位置继续，部分累积梯度不会作为恢复点。
OOM后保留日志，最多重试三次；有checkpoint时恢复，否则创建新尝试目录重新使用共同起点。
其他错误停止并写明原因。各子任务启动前检查GPU剩余显存，实验日志和checkpoint分别保存。

入口：`scripts/prepare_perception_ablation.py`、`scripts/run_perception_ablation_suite.py`、
`scripts/train_perception_ablation.py`、`resworld/perception_ablation.py`。
