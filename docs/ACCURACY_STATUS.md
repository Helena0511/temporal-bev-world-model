## 已确认的现象

1. 原mini没有右转训练样本；当前城市小试验已改用48条场景多样、路线均衡的训练序列，
   配套24条官方独立场景验证序列。
2. 旧BEV范围不够；当前城市小试验的训练/验证GT及初始轨迹参考点越界率均为0。
3. 当前模型连训练数据也没有拟合好：训练ADE 2.9526m，匀速1.9069m；验证ADE 2.6349m，匀速1.8863m。
   仅用“验证泛化不好”无法解释训练样本本身的大误差。
4. 存在明显的速度映射偏差：训练中≥5m/s组纵向有符号平均误差-3.0902m，
   <2m/s组+1.3760m，2–5m/s组+1.7137m，即较快样本偏短，较慢样本偏长。
   一条过去车速15.92m/s的样本，真实3秒末位置[47.69,-3.21]m，预测[18.02,-1.19]m。
   其纵向错误不能用简单的未来不确定性解释；过去运动本身已经给出很强的距离参照。

## 已完成首轮对照的针对性方案

候选为“过去运动学轨迹 + 学习位移修正”，对应 `ModelConfig.kinematic_prior=True`。
初始位移由当前/历史位姿和过去时间间隔计算，两个修正头零初始化，使训练前精确退化为匀速基线。
不读取未来轨迹；模型仍学习加减速、转向和世界特征相关的修正。

这是独立的改进变体，改变了原生模型的轨迹参数化，**不是纯粹的原版ResWorld复现**。
原模型及其默认配置保持不变，权重与日志单独保存在 `runs/city_phase1/pilot_prior/`。
对照采用相同48/24条数据、seed=0、图像尺寸、感知网络、优化器、两轮训练和48次更新。
新增测试检查匀速初值、旋转坐标系下的速度方向、无效时间间隔和可学习修正梯度；合计40项测试通过。

相同24条独立验证序列、相同两轮预算下的结果：

| 指标（米） | 原城市模型 | 运动学先验变体 | 匀速基线 |
| --- | ---: | ---: | ---: |
| ADE | 2.6349 | 1.6096 | 1.8863 |
| 纵向平均绝对误差 | 2.5114 | 1.3280 | 1.3400 |
| 横向平均绝对误差 | 0.4247 | 0.6382 | 1.0133 |
| 3秒终点误差 | 4.7240 | 3.4946 | 4.0099 |

运动学残差参数化在这个小试验的ADE比原城市模型低约38.9%，比匀速低约14.7%，
改善主要来自纵向；横向比原城市模型变差，不能宣称所有指标均改善。
这是一个seed和24条验证的结果，不证明在完整验证集、不同随机种子或其他工况下稳定有效。
两个模型的初始化策略随参数化不同；该实验比较的是整个运动学残差变体，
不能进一步把收益唯一归因于某个层、损失或世界模块。
较大正式配置尚未默认启用此变体，需要先扩大实验和验证模块归因。

## 尚未完成的归因

- 速度信息为何没有被原参数化充分利用：训练步数不足、状态条件经过归一化后的幅值表达、
  模型容量、逐步位移损失对累计偏差的约束，仍需分别对照；现在不能认定其中某一项是唯一原因。
- 视觉仍弱：需要深度/语义质量检查、预训练编码器与更充分训练后的去图像测试。
- 世界模型与FGTR：需要在相同先验、数据和预算下独立重训开关对照，而非只看推理置零结果。
- 小样本结果需要更大场景集和多个随机种子验证；当前数据选择还是速度代理，尚无完整城市道路/交互真值标签。

因此，当前阶段应先消除明显的速度/距离拟合问题，再验证感知和残差分支的增益，
还不适合宣称精度问题已全部解决。
